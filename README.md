# HMM ITB PWA Frontend — Legacy

> **Legacy repository.** This project contains an earlier frontend iteration of the HMM ITB progressive web application. The newer integrated platform is maintained in [`hmm-lms`](https://github.com/soezyxstt/hmm-lms).

This repository is kept public as a historical snapshot of the frontend work and the evolution of the HMM ITB digital platform.

## Stack

- Next.js
- React + TypeScript
- Tailwind CSS
- shadcn/ui
- React Hook Form

## Status

No active feature development is planned here. For the current system architecture, application features, and development instructions, see:

- [`soezyxstt/hmm-lms`](https://github.com/soezyxstt/hmm-lms)

## Historical context

This frontend was part of the earlier HMM ITB PWA effort before functionality was consolidated into the broader HMM learning and community platform.
